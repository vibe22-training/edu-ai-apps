# 초등 3학년 수업용 퀴즈 생성기 요구사항 명세서 (교사 업무 절감형 v2)

## 1. 문서 개요

- 문서명: 초등 3학년 수업용 퀴즈 생성기 요구사항 명세서 (교사 업무 절감형 v2)
- 대상 사용자: 초등학교 3학년 담당 교사
- 목적: 교사가 반복적으로 수행하는 활동지 제작 업무를 줄이고, 단원 적합도와 난이도 일관성을 확보한다.
- 작성 기준: 본 문서는 대화 요구사항과 제공된 준비작업(활동지/단원문항/모둠활동) 페인포인트를 반영한다.

## 2. 배경 및 문제 정의

### 2.1 현재 준비작업과 빈도

1) 활동지 새로 만들기: 주 2회  
2) 단원 문항 만들기: 단원마다  
3) 모둠 활동 아이디어 찾기: 차시마다

### 2.2 핵심 불편사항

1) 문항을 하나씩 직접 작성해야 해서 시간 부담이 큼  
2) 단원 문항을 만들 때 단원 정합성 확보가 어려움  
3) 난이도 맞추기가 어려워 수준 편차가 큼  
4) 준비물/결과물 확인에 시간이 오래 걸림

## 3. 서비스 목표

### 3.1 1차 목표

- 교사가 교과·단원·난이도를 입력하면 4지선다형 문항을 자동 생성한다.
- 기본 결과는 카드 형태로 제공해 검토·수정·선택을 빠르게 한다.
- 로그인 없이 즉시 사용할 수 있게 한다.

### 3.2 운영 목표(교사 업무 절감)

- 주 2회 반복되는 활동지 제작 시간을 유의미하게 단축한다.
- 단원 적합성 검증 장치를 제공해 문항 품질 확인 시간을 줄인다.
- 난이도 기준을 시스템화해 문항 난이도 편차를 줄인다.

## 4. 범위

### 4.1 포함 범위

- 교과/단원/난이도 입력
- 핵심개념(키워드) 입력 보조
- 4지선다 문항 자동 생성
- 카드형 결과 표시
- 전체 재생성 및 문항별 재생성
- 난이도 자동 배분
- 학생용/교사용 결과 분리 제공

### 4.2 제외 범위

- 로그인/회원가입/권한관리
- 사용자별 클라우드 저장/이력 관리
- 결제/구독

## 5. 사용자 시나리오

### 5.1 기본 시나리오

1) 교사가 교과, 단원, 난이도, 핵심개념을 입력한다.  
2) 시스템이 4지선다 문항 세트를 생성한다.  
3) 결과를 카드 단위로 검토한다.  
4) 필요 시 전체 또는 특정 문항만 재생성한다.  
5) 학생용(문제만)과 교사용(정답/해설 포함) 형태로 활용한다.

### 5.2 빠른 운영 시나리오(주 2회 모드)

1) 이전 입력값(교과/단원/난이도/배분)을 자동 유지한다.  
2) 단원만 바꿔 즉시 재생성한다.  
3) 부족한 문항 1~2개만 문항별 재생성으로 보정한다.

## 6. 기능 요구사항 (Functional Requirements)

### FR-01 입력 기능

- 교사는 다음 항목을 입력할 수 있어야 한다.
  - 교과(예: 국어, 수학, 사회, 과학)
  - 단원명(자유 텍스트)
  - 핵심개념 키워드 3~5개(예: 분수, 진분수, 가분수, 통분)
  - 난이도(쉬움/보통/어려움 또는 혼합 모드)
- 입력 누락 시 항목별 오류 메시지를 표시해야 한다.

### FR-02 문항 생성 기능

- 시스템은 기본 5문항을 생성해야 한다.
- 확장 생성 옵션으로 10~15문항 생성 모드를 제공해야 한다.
- 모든 문항은 4지선다 형태여야 하며 아래 요소를 포함해야 한다.
  - 문제 본문
  - 선택지 4개
  - 정답 1개
  - 해설(1~2문장 권장)

### FR-03 난이도 제어 기능

- 난이도 자동 배분 규칙을 제공해야 한다.
  - 기본 예시: 쉬움 2 / 보통 2 / 어려움 1 (5문항 기준)
- 생성 후 각 문항의 난이도 라벨을 표시해야 한다.
- 교사는 문항 단위로 “더 쉽게/더 어렵게” 재생성 요청을 할 수 있어야 한다.

### FR-04 단원 정합성 기능

- 생성 문항마다 단원 적합도 상태를 표시해야 한다.
  - 상태값: 적합 / 주의
- 단원명·핵심개념과 관련성이 낮은 문항은 ‘주의’로 표시해야 한다.

### FR-05 카드형 결과 표시 기능

- 결과는 문항별 카드로 표시되어야 한다.
- 카드 1개에는 최소 다음 정보가 포함되어야 한다.
  - 문항 번호
  - 문제 본문
  - 선택지 4개
  - 정답
  - 해설
  - 난이도 라벨
  - 단원 적합도 상태

### FR-06 재생성 기능

- 전체 재생성: 현재 입력 조건으로 전체 문항 세트를 새로 생성한다.
- 문항별 재생성: 선택한 카드 1개만 재생성한다.
- 재생성 결과는 기존 카드와 즉시 교체되어야 한다.

### FR-07 출력 모드 기능

- 학생용 모드: 문제+선택지만 표시(정답/해설 숨김)
- 교사용 모드: 문제+선택지+정답+해설 표시

### FR-08 빠른 모드 기능

- 최근 사용 입력값 자동 유지 기능을 제공해야 한다.
- 반복 제작 시 클릭 수를 최소화하는 ‘빠른 생성’ 진입 방식을 제공해야 한다.

## 7. 비기능 요구사항 (Non-Functional Requirements)

### NFR-01 사용성

- 교사가 별도 매뉴얼 없이 사용할 수 있어야 한다.
- 초등 3학년 수준 어휘와 문장 길이를 우선 적용해야 한다.

### NFR-02 성능

- 생성 요청 후 5초 이내 결과 표시를 목표로 한다(권장).

### NFR-03 신뢰성

- 5문항 생성 모드에서 정확히 5문항이 생성되어야 한다.
- 모든 문항은 선택지 4개, 단일 정답 1개를 보장해야 한다.

### NFR-04 품질 일관성

- 학년 초과 어휘, 과도한 복합 지시문, 과도한 함정 선택지 포함 시 경고를 제공해야 한다.

### NFR-05 보안/개인정보

- 로그인 기능을 제공하지 않는다.
- 개인정보 수집/저장을 전제로 하지 않는다.

## 8. 데이터 요구사항

### 8.1 입력 데이터

- subject: 교과
- unit: 단원명
- key_concepts: 핵심개념 키워드 목록(3~5개)
- difficulty_mode: 단일 난이도 또는 혼합
- difficulty_distribution: 난이도 배분(예: easy2/normal2/hard1)

### 8.2 출력 데이터(문항 단위)

- question_id
- question_text
- options[4]
- correct_option
- explanation
- difficulty_label
- unit_fit_status(적합/주의)

## 9. 오류 및 예외 처리

- 교과 미입력: “교과를 입력해 주세요.”
- 단원 미입력: “단원을 입력해 주세요.”
- 난이도/배분 미선택: “난이도 또는 배분을 선택해 주세요.”
- 핵심개념 부족: “핵심개념을 3개 이상 입력해 주세요.”
- 생성 실패: “문항 생성 중 문제가 발생했습니다. 다시 시도해 주세요.”

## 10. 수용 기준 (Acceptance Criteria)

1) 교과·단원·난이도(또는 배분) 입력 후 문항이 생성된다.  
2) 기본 모드에서 정확히 5문항이 생성된다.  
3) 각 문항은 4지선다, 정답 1개, 해설을 포함한다.  
4) 결과가 카드 형태로 표시된다.  
5) 전체 재생성과 문항별 재생성이 모두 가능하다.  
6) 문항별 난이도 라벨과 단원 적합도 상태가 표시된다.  
7) 학생용/교사용 표시 모드가 분리된다.  
8) 로그인 없이 즉시 사용할 수 있다.

## 11. 향후 확장 항목 (현 범위 외)

- 활동지 템플릿 고정(이름/날짜/단원 자동 삽입)
- 인쇄/PDF 내보내기
- 단원별 문항 라이브러리
- 모둠 활동 아이디어 자동 제안 기능 연계
